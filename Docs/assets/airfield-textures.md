# Airfield textures and materials

These are the ground textures for runways, taxiways, aprons, dirt and grass strips and the field, plus the noise and
glyph atlas the airfield shaders use. All are generated by `ArtSource/Airfield/textures.py`, which is plain
Python 3 (numpy, Pillow, scipy), not Blender, and writes to `Assets/AirCity/Airfield/Textures/`.

## Sets

| Set | CC0 source | Matched mean albedo (sRGB) | Used by |
|---|---|---|---|
| Asphalt | Poly Haven `clean_asphalt` | 0.25, 0.25, 0.26 | Asphalt material; also runway shoulders and blast pads |
| AsphaltWorn | Poly Haven `asphalt_02` | 0.36 | worn asphalt |
| Concrete | Poly Haven `concrete_floor_03` | 0.64, 0.63, 0.60 | Concrete |
| ConcreteWorn | Poly Haven `cracked_concrete_02` | 0.52, 0.51, 0.48 | worn concrete |
| Dirt | Poly Haven `dirt` | 0.47, 0.40, 0.31 | Dirt |
| DirtWorn | Poly Haven `brown_mud_02` | 0.38, 0.31, 0.23 | worn dirt; also the worn texture of GrassStrip (bare patches) |
| Grass | ambientCG `Grass004` | 0.30, 0.38, 0.15 | Grass (the field), GrassStrip |

The sources are downloaded once into `ArtSource/Airfield/Build/downloads` (gitignored). They're CC0, so they're fine
in the public repo.

**Per set, 1024² each:**

| File | Contents |
|---|---|
| `<Set>_Albedo` | sRGB; flattened, colour-matched; `keep` = the share of the source's colour kept |
| `<Set>_Normal` | OpenGL convention |
| `<Set>_Mask` | R roughness, G AO, B height; linear |

**Shared:**

| File | Contents |
|---|---|
| `Macro.png` (512², linear) | four tileable 1/f noises: R large blobs (tint, wear patches), G medium (sample blend, puddles), B fine (streaks, snow edges), A grain (ragged edges, paint wear) |
| `RunwayGlyphs.png` (1024 × 512, one channel) | SDF of `0123456789LCR`; cells 128 × 256 px at 24 px/m, a 3 × 9 m box, stroke 0.8 m, spread 0.66 m |

Keep `CHARS`, `CELL`, `PX_PER_M` and the atlas size in sync with `PaintBuilder.cs`.

## Commands

```sh
python3 ArtSource/Airfield/textures.py            # everything
python3 ArtSource/Airfield/textures.py Glyphs     # one set: Asphalt, Dirt, ..., Macro, Glyphs
```

Then run the airfield bootstrap. `AirfieldTexturePostprocessor` sets the import rules: albedo sRGB, normal maps,
masks linear, the glyphs single-channel uncompressed and clamped, anisotropic filtering 16, max size 1024.

## Materials (Assets/AirCity/Airfield/Materials)

`AirfieldSetup.CreateMaterials` creates **missing materials only**, so hand-tuning survives. To get new defaults,
delete the `.mat` (keep the `.meta`) and rerun the bootstrap. The surface looks are set in `AirfieldSetup.Surfaces`:

| Material | Shader | Notes |
|---|---|---|
| Concrete | AirfieldSurface | 2.5 m tile; joints 7.5 × 7.5 m; rubber 0.9 |
| Asphalt | AirfieldSurface | 2.1 m tile; 5 m lane joints (faint); rubber 0.6 |
| Dirt | AirfieldSurface | `_FRINGE`; brown rubber; puddles 0.7 |
| Grass | AirfieldSurface | the field; puddles 0.15 |
| GrassStrip | AirfieldSurface | grass runways and taxiways: worn set = DirtWorn, `_FRINGE` + `_GRASS_LENGTH` (length tint, seed heads, mowing stripes, `_StripeStrength` 0.2) |
| Paint | AirfieldPaint | glyph atlas plus macro noise |
| LightGlow | AirfieldLightGlow | |
| Fixture | AirfieldFixture | |

## Look history

- **Dirt:** the colour was retuned to a warmer brown (target 0.47, 0.40, 0.31, chroma 0.85).
- **Runway numbers:** the stroke was thickened from 0.62 to 0.8 m because the numbers read too thin.
- **Grass:** the yellow patches were reduced.
- **Snow:** the first version was pure white and blotchy. It now uses a darker snow albedo (0.5, 0.52, 0.56), softer
  coverage and noise mixed from height, fine noise and grain.
- **Far ground in heavy snow:** it reads very uniform; this is a known look issue.
